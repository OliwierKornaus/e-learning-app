1. Teoria — Funkcje w Kotlinie

Funkcje w Kotlinie służą do wykonywania określonych operacji i pozwalają organizować kod w czytelny sposób. Funkcję definiujemy przy użyciu słowa kluczowego fun. 


fun dodaj(a: Int, b: Int): Int {
    return a + b
}

Kotlin wspiera również funkcje jednolinijkowe, parametry domyślne, funkcje lambda oraz programowanie funkcyjne.
